artifact; REPO-INSPECTION describes inspected code; SCHEMA-ONLY means a schema
without runtime integration; UNVERIFIED means not verified.

variant. Example UUIDv7: `01950000-0000-7000-8000-000000000001`. Do not commit
credentials, provider-generated IDs, machine identifiers, absolute home paths
