# Configuration and usage

Mode: Operate. Routes: /usage, /agents, /agents/new, /agents/:slug/edit,
/agents/:slug/duplicate, /settings.

THESIS: Understand shared provider allowances and configure a named agent for
CLI use without turning the dashboard into an execution console.
OWN-WORLD: User-approved HTML concept, Focus navigation, system font, quiet
green, neutral ground, thin rules, restrained borders and compact forms.
STORY: Reported allowance → saved agent roles → stable CLI configuration lookup.
FIRST VIEWPORT: Three navigation links, provider/account identity, observed
window values or explicit unknown, reset and last-observation timestamps.
FORM: Code-led extension of the accepted HTML concept; no approved raster comp.
SIGNATURE INTERACTION: Switching a role's provider resets the model choice to
that provider's configured catalog while preserving the rest of the draft.
FINISH: Desktop/mobile review, detector, fresh finish reviewer and documenter.
BOUNDARY: CLI execution binding and approval flows remain separate work.
